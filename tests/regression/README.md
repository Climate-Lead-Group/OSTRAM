# tests/regression — unittest regression suites for the OSTRAM package

Characterisation and contract tests for the CLI, path resolution, profiles, the A3, B1 and B2
stages, the reporting layer and the accepted baseline. All files are `unittest.TestCase` suites
collected by pytest or `unittest discover`; subprocess and solver boundaries are mocked except
where noted. `accepted_baseline.py` is a helper CLI, not a test. Run counts and the pre-existing
failures as of 2026-09-29 are recorded in `AGENTS.md`, "Known gotchas".

## How to run

From the repo root:

```bash
PYTHONPATH=tests python -m pytest tests/regression -q      # PowerShell: $env:PYTHONPATH="tests"
python -B -m unittest discover -s tests/regression -p "test_*.py" -v
```

## Gotchas

- Writes inside the tree: `test_b1_runner.py`, `test_run_orchestration.py` and
  `test_run_terminal.py` create temp dirs under `tests/regression/` (removed per test, a
  cleanliness risk if a run is killed); `test_materialization_paths.py` creates them in the parent
  of the repo; `test_paths.py` creates and never removes
  `workspace/stage11-lazy-test/<Scenario With Space uuid>/` and needs `workspace/` to exist.
- Real subprocesses: `test_canonical_cli.py` (`python -m ostram --help`), `test_b2_orchestration.py`
  (an isolated `-I` interpreter importing `ostram`, which needs an editable install visible to it),
  `test_manual_fix_domain.py` (`apply_manual_fixes`), `test_run_terminal.py` (child scripts),
  `test_accepted_baseline.py` (`git`).
- `test_support_bau_transmission.py` needs `tests/` on `sys.path`;
  `test_restriction_prerequisites.py` needs the repo root. Both hold with `PYTHONPATH=tests` from
  the repo root.
- Many suites open real `.xlsx` files with openpyxl; on Windows with pandas 3 this is where the
  file-lock `PermissionError` failures listed in `AGENTS.md` come from.
- `test_scenario_concatenation.py` compares dated copies against today's date and is sensitive to
  a midnight rollover; `test_reserve_margin_warning_paths.py` has a Windows-only case.
- `test_interconnector_taxonomy_path.py` and `test_run_orchestration.py` change the working
  directory with `os.chdir`, so they are not thread-safe.
