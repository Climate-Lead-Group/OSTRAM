# Historical cleanroom test harness

This directory preserves the one-time cleanroom comparison harness and its frozen
hero references. It is historical evidence, not current acceptance authority and
not an instruction to execute model stages, batch files, a matrix generator, or a
solver.

Current no-solver validation requirements are maintained in
[`docs/regression.md`](../docs/regression.md). The accepted 15-scenario compiled-input
record is
[`accepted_compiled_solver_baseline_15.json`](../tests/regression/reports/accepted_compiled_solver_baseline_15.json).
`cleanroom_check.py` and `hero_refs/` remain preserved for lineage.
