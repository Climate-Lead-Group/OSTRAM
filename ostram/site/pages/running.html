Running the model

OSTRAM runs from one command, python -m ostram, in a conda environment. Install it, check that it finds its files, then build a first scenario without a solver before running a full solve.

In five steps

  1. 1

    Get the tools

    Git, conda (Miniforge) and a solver. Use a short local path, not a synced cloud folder.

  2. 2

    Clone and create the environment

    git clone https://github.com/Climate-Lead-Group/OSTRAM
cd OSTRAM
conda env create -f environment.yaml
conda activate OSTRAM-env
python -m pip install -e .
  3. 3

    Check the installation

    python -m ostram --help
python -m ostram inspect-resources
  4. 4

    Build a scenario without a solver

    The quickstart below shows a compile-only run, which prepares and compiles the model inputs and stops before the solve.

  5. 5

    Solve and read the results

    Run the configured workflow, then check the run as checking a run describes.
