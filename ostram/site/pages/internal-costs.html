Internal transmission costs

Every gigawatt of internal grid the model builds costs money, and that cost competes with plants placed closer to demand and with imports. OSTRAM computes the cost in every run from a small set of sourced inputs, so the same formula can be reused with another region's data.

The formula, worked with the released inputs

The base cost is a published regional line cost brought to the model's cost year with the World Bank manufactures unit value index. Renewable plants pay an add-on for pooling stations and connection lines, taken from India's Green Energy Corridor programme; the configuration records it as an assumption. The fixed cost is a share of the capital cost paid every year. The internal grid of every node uses the same values.

Two ways to change it

  • For every scenario: change a key of the internal_transmission block of the country configuration. The flat placeholder blocks of the internal families in the same file are overwritten by the rule, so editing them changes nothing.
  • For one scenario: add a scenario edit that sets the cost of the internal families in that scenario only.
