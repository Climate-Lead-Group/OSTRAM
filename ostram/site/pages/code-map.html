Pipeline and code map

A run goes through the stages A1 to B2. The A stages prepare and change workbooks; the B stages compile them into model files and solve. A3 is the stage that applies your scenario's rules and edits, so it is where most of your numbers change.

Where to confirm an edit

A workbook cell can be rewritten by a later stage. Confirm a change in the compiled input files of the scenario and in the solver datafile, not in the file you edited. The pipeline reference below lists what each stage reads and writes.
